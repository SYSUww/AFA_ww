# B 榜规则选择题检索词审计（2026-07-24）

## 1. 目的与边界

本审计覆盖当前完整 100 题候选中，答案阶段未调用模型、由确定性规则完成选项判断的 48 道选择题。

目标是从已保存的最优证据链反推每题真正需要检索的语义槽位，并进一步归纳可泛化的查询生成规律。逐题词表只用于诊断和离线检索评测，禁止以 `QID -> 关键词/答案` 的形式接入生产链路。

事实来源：

- 答案与证据链：`artifacts/b_board_actual/qwen37_integrated_full100_candidate_a13_reasoning_provenance/answers.json`
- 题目：`upload_b/question_b/*`
- 当前各领域 solver 的定向检索与规则分支

这里的“最优证据链”是当前工程产物中的检索伪金标，用于评估证据召回，不代表官网确认的正确答案，也不用于反推隐藏标签。

统计口径：

- `decision_trace.answer_api_usage_ledger.call_count == 0`
- 题型属于 `multi`、`mcq` 或 `tf`
- 共 48 题：金融合约 14、财务报告 10、保险 8、监管 2、行业研究 14

## 2. 词表字段

每题按以下字段整理：

- **文档锚点**：报告、主体、产品、法规或材料身份。
- **主题/对象词**：需要核验的条款、指标、事件或对象。
- **关系/动作词**：计算、比较、适用、限制、给付、披露等关系。
- **数值/时间/口径词**：年份、阈值、单位、报表口径、分母或期限。
- **范围/极性词**：所有、仅、至少、不超过、不得、无需、例外等。
- **支持查询**：用于召回直接支持命题的证据。
- **反证查询**：保留主题和关系，但弱化或替换选项中的结论值，用于寻找不同数值、范围、主体或例外。
- **决定性证据**：当前最优证据链中的 unit id 及其最小事实摘要。
- **可自动生成性**：哪些词可从题目/选项抽取，哪些需要通用领域词典或同义扩展。

## 4. 跨题规律

### 4.1 所有领域共享的查询槽位

48题虽然领域不同，但决定性证据几乎都可以表示成同一组槽位：

```text
文档/实体锚点
+ 主题对象
+ 关系/动作
+ 数值、日期或期限
+ 口径、范围和极性
+ 例外条件
```

生产查询应从题面动态填槽：

- 公司名、产品名、法规名、报告名只要来自题面，就可以作为动态文档锚点。
- 数值、年份、期限必须与对应主体和指标绑定，不能作为脱离上下文的全局关键词。
- `所有、均、仅、任何、完全、至少、不超过、不得、无需、未明确、未提及、例外` 等范围/极性词具有高判别力，不能在停用词清洗中丢弃。
- 同一槽内的同义词采用 OR，例如 `核爆炸 OR 核反应`；不同必要槽之间采用 AND 或覆盖门禁。

### 4.2 一个选项至少生成三类查询

不能只搜索与选项原句一致的材料，否则会产生确认偏差。建议每个原子命题至少生成：

1. **精确支持查询**
   - `主体 + 主题 + 关系 + 选项数值/范围`
2. **去结论宽查询**
   - `主体 + 主题 + 关系`
   - 暂时移除选项声称的数值或结论，用于找报告真正披露的值。
3. **反证/例外查询**
   - `主体 + 主题 + 否定、替代值、例外、不同范围`
   - 替代词来自通用反义/范围词典和同一章节候选值，不能来自已知答案。

例如“官网公示30日就足够”：

```text
支持：支付收费调整 官网 公示 30个自然日
宽查：支付收费调整 公示渠道 办理前义务
反证：经营场所 公众号 办理关键节点 用户知悉 接受
```

### 4.3 先拆原子命题，再检索

长选项经常包含多个判断，必须拆开：

```text
主体 × 指标/条款 × 关系 × 时间/口径
```

- 财报题拆成“公司 × 年份 × 原始指标”，计算和排序放到检索之后。
- 跨合同题拆成“发行人 × 条款 × 条件/例外”，禁止跨文档拼证据。
- 保险题拆成“产品 × 免责/责任条款 × 完整要素”。
- 行业研究题拆成“行业/主体 × 成本/性能/壁垒等关系维度”，逐主体召回后再做跨行业归纳。

### 4.4 六类最重要的通用能力

| 能力 | 典型题目 | 需要解决的问题 |
|---|---|---|
| 主体和文档绑定 | `fc_b_006/008`、保险8题、研究14题 | 相似条款不能跨公司/产品/报告串联 |
| 数值、年份、单位绑定 | 财报10题、`fc_b_004/011/012` | 百分点 vs 相对百分比、倍数、每股/每10股、年份列 |
| 条件—结果—例外链 | `fc_b_003/010/012/015/018`、保险条款 | 找到主题词不等于满足完整条件 |
| 范围和极性 | 大量多选题 | `所有/仅/完全/不得/无需/至少`决定真假方向 |
| 全文存在性/缺失证明 | `fc_b_006/007/008/009`、部分保险题 | Top-K未命中不能证明“未提及” |
| 多主体覆盖矩阵 | 财报比较、跨合同、行业研究 | “均/都/共同/完全一致”要求每个主体都被证据覆盖 |

### 4.5 各领域最合适的首轮检索模板

| 领域 | 首轮模板 |
|---|---|
| 金融合约 | `报告/发行人 + 条款标题 + 条件 + 权利义务 + 数值/期限 + 例外` |
| 财务报告 | `公司 + 报告期 + 报表/附注口径 + 原始指标名 + 表头年份` |
| 保险 | `产品全名 + 责任/免责章节 + 条款要素 + 数值期限 + 例外` |
| 监管 | `法规/事项 + 适用主体 + 义务动作 + 条文期限/生效日 + 例外` |
| 行业研究 | `行业/事件 + 主体行为 + 因果维度`，首轮定位报告后再追加实体别名 |

### 4.6 不能直接进入生产代码的内容

以下内容可以留在离线审计和检索评测中，但不能成为生产规则：

- `QID -> 关键词、doc_id、unit_id、True/False、最终答案`
- 固定某道题的公司组合、年份组合或选项顺序
- 根据已知答案决定只搜支持证据或只搜反证
- 将当前 `pack2_textXX`、`textXX` 直接映射到题目
- 以 Top-K 未命中直接判定“全文没有”

可以进入生产代码的是：

- 从题面动态抽取的实体、年份、数值、条款和范围词
- 跨题复用的指标/条款同义词典
- 通用的表格口径、期间、单位和条件关系解析
- 同时执行支持、宽查和反证查询的策略
- 可观测的证据覆盖门禁

### 4.7 当前审计发现的两个特殊风险

1. `fc_b_007`：冻结 evidence 中缺少 reasoning 所使用的“40,500万元采购意向”原文，证据链尚未闭环。
2. `ins_b_016`：材料语义证据支持 `ABD`，但历史官网差分曾指向 `BD`；这是 benchmark 标签冲突，不是检索词优化可以消除的问题。

## 5. 后续检索评测建议

逐题词表完成后，应在不使用固定 QID、固定答案和人工指定目标 chunk 的条件下进行离线检索回放，至少报告：

- 正确文档 Recall@1 / Recall@3
- 决定性证据 Recall@5 / Recall@10
- 决定性证据 MRR
- 逐选项证据覆盖率
- 反证召回率
- 主体、年份、口径和极性绑定错误数

只有当通用查询生成器能在上述指标上稳定召回证据，才进入“移除固定 True/False，恢复模型或通用判定器”的下一阶段。
