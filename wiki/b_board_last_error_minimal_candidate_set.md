## 历史提交能给出的进一步分组

11 次官网提交实际扰动过 13 道题，其中 9 道已经完成归因。剩余 4 道“改过但未归因”的题为：

```text
fin_b_013
fin_b_017
res_b_005
res_b_012
```

其中前三道在提交 002→003 中一起增加 `%`，组合净效果为 `+1`：

```text
effect(fin_b_013)
+ effect(fin_b_017)
+ effect(res_b_005)
= +1
```

单题效果只能取 `-1/0/+1`，三题合计 `+1` 的结构只有：

```text
(+1, 0, 0)
(+1, +1, -1)
```

其中 `0` 既可能表示前后格式被平台视为等价，也可能表示前后答案都错。因此，在理论 99% 只剩一错的条件下，至少有以下三类解释：

| 解释 | 三题当前状态 | 最后一错位置 |
|---|---|---|
| 一题 `+1`，另外两题格式等价 | 三题当前都正确 | 三题之外 |
| 一题 `+1`，一个 `0` 为格式等价，另一个 `0` 为前后都错 | 三题中一题仍错 | 效果为 `0` 的内容错误题 |
| 两题 `+1`、一题 `-1` | 两题当前正确、一题被改错 | 效果为 `-1` 的题 |

结合题面措辞和既有原始材料审计，当前最值得区分的两个具体假设是：

1. `fin_b_013=-1`、`fin_b_017=+1`、`res_b_005=+1`：`fin_b_013` 的“均不带单位”被官方解释为不带 `%`，当前 `40.05%` 是最后一错；
2. `res_b_005=0（前后都错）`，`fin_b_013/fin_b_017` 一项为 `+1`、一项格式等价：`res_b_005` 的 `22.27%` 存在基期口径问题，是最后一错。

还存在“三题当前都正确、最后一错位于其他 87 道”的解释。现有官网成绩不能在这些假设之间选择。

### 哪一道最可能贡献了确定的 `+1`

在三题中，`fin_b_017: 0.08→0.08%` 最可能是至少一道真实正向修正：

1. 题干明确写“后者以百分数计并保留两位小数”，对百分数语义的要求比另外两题更直接；
2. README 明确要求百分数答案填写 `%`；
3. 原始年报数据可以稳定复算：

```text
隐含营业收入 = 338931 ÷ 32.3% = 1049321.9814... 百万元
绝对相对偏差
= |1049321.9814... - 1050187| ÷ 1050187 × 100%
= 0.082368...%
→ 0.08%
```

4. 两轮独立证据审计均给出 `1049321.98；0.08%`，置信度分别为 99 和 100，没有替代口径。

相较之下：

- `fin_b_013` 的数值很稳，但“均不带单位”使 `%` 是否应出现存在格式解释空间；
- `res_b_005` 虽然按 `45.8kWh` 可算得 `22.27%`，但历史审计记录过从未舍入基期反推得到 `22.19%` 的替代口径。

因此可把 `fin_b_017=+1` 作为当前最高置信工作假设，但它仍不是官网单题确认。代入后：

```text
effect(fin_b_013) + effect(res_b_005) = 0
```

这会把下一步重点收敛到 `fin_b_013` 与 `res_b_005` 的格式/数值真值审计。

其余 **87 道**题从未被官网提交做过独立答案扰动。对其中任意一道，都能构造出“该题从提交 001 开始一直答错、其余分数变化由已知改动解释”的兼容状态，因此不能仅凭历史总分排除任何一道。

## 可执行结论

- **官网严格集合：91 道。**
- **接受 `res_b_012` 自包含计算证据后的集合：90 道。**
- 三道百分号题是历史上唯一“改过但尚未单题归因”的小组，信息结构特殊，但并不意味着最后一题必在其中。
- 若要继续缩小集合，必须引入逐题证据审计；仅重复分析现有官网总分不会产生新的方程。
